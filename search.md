# Live Search Across Panels

The search bar at the top of each panel filters results in real time. Behavior changes depending on which panel is active.

| Panel | What It Searches | Notes |
| --- | --- | --- |
| 📚 Library | Title + author across all books | Folder context is remembered; returns to it when search clears. Folder chips filter to show only folders with matching books. |
| ♥ Favorites | Title + author in favorites only | Empty state shown if no favorites match. |
| 🏛️ Discover | Title + author in catalog list | No search available in Mosaic view — mosaic is visual-only. |
| ⏳ Recall | — | Search bar not active in Recall panel. |

> **INFO:** Clicking the right edge of the search bar (near the folder icon) opens the Create Folder quick action — a shortcut for organizing your library without hunting for the button.
