# Book Trivia

Recall generates quiz questions about books in your own library — using the actual text, metadata, and characters. Questions are different every time.

1. **Pick a book** — Choose any book from your library that has content. Books with more text generate more and harder questions.
2. **Choose difficulty** — Easy · Medium · Hard. Each has different question types and a different number of questions (3–8 based on available content).
3. **Answer questions** — Multiple choice or open-ended. Each question shows an explanation after answering. Score tracked in real time.
4. **See your result** — A score summary with milestone celebration if you do well. Option to replay or pick a different book.

#### Familiar Facts (Easy)

  - `MC` Who wrote this book? 4 options — Correct author vs 3 others from your library
  - `MC` What genre is it? 4 options — Picked from genres in your library
  - `MC` Length category? 4 options — Short / Medium / Long / Epic
  - `MC` Which book did this author write? 4 options — Reverse: given author, pick the title
  - `MC` How many pages? 4 ranges — Under 150 / 150–350 / 350–600 / Over 600
  - `MC` Which book starts with this passage? 4 titles — Shows first 90 characters of the book's opening

#### Deeper Knowledge (Medium)

  - `MC` Who is the main character? 4 options — Detected from text by frequency, sentence position, action verbs
  - `MC` Which character appears in this book? 4 options — Secondary character + 3 distractors from other books
  - `MC` Which word recurs most? 4 options — Top thematic keyword from text analysis vs mid-frequency distractors
  - `open` Complete the opening line Type answer — First sentence shown up to 35–65% — complete the rest
  - `MC` Author / Genre / Page count — Same as Easy but used when no text questions are available
  - `MC` Year first published? 4 years — Only shown when publication year is available in metadata

#### Expert Level (Hard)

  - `open` Complete this passage Type answer — A real quote from the book, cut at a clause break — complete the second half
  - `MC` Central character? 4 options — Protagonist detected by cross-section presence, sentence-subject analysis, inner-life references
  - `MC` Most thematically repeated word? 4 options — Harder variant — distractors come from the same book
  - `MC` Which name is NOT in this book? 4 names — 3 real characters from this book + 1 intruder from another book
  - `MC` One of its genres? 4 options — Only for multi-genre books — requires picking the less obvious genre
