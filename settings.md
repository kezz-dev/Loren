# Settings & Customisation

Accessible from the ⚙️ gear icon in the topbar overflow menu (···).

- **🌙 Dark Mode** — Switches the entire app to a dark navy/charcoal palette. All colors and shadows adjust automatically. Options: **Light** (default), Dark.
- **🌡 Warm Night** — Adds an amber/parchment tint to both light and dark modes. Light becomes aged paper; dark becomes deep ember embers. Options: **Off** (default), On.
- **🔤 Reading Font** — Changes the font used throughout the app, including in the PDF reader. Options: **Inter (default)** (default), Merriweather, Lora, Montserrat, Courier Prime.
- **✨ Animations** — Enables or disables all UI animations and transitions. Off is useful for accessibility or performance on slower devices. Options: **On** (default), Off.
- **📊 Library Layout** — Switch between List, Grid, and Shelf view. Persists between sessions. Options: List, **Grid** (default), Shelf.
- **👤 Your Name** — Set your name so Loren greets you personally ("Hi Teni —"). Optional. Options: [text field].
- **💾 Export Library** — Download a full JSON backup of your library — books, notes, folders, favorites, and reading history. Options: Download.json.
- **📥 Import Library** — Restore a previously exported backup. Merges with or replaces existing data. Options: Upload.json.

### Topbar Overflow Menu (···)

- **⚙️ Settings**: Opens the full settings panel with theme, font, and data options.
- **📊 Reading Insights**: Shortcut to open the Reading Insights dashboard directly.
- **🔍 Find Duplicates**: Scans your library for possible duplicate books and presents them for review.
