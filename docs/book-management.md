# Book Management

Everything you can do with a book — from adding it to deleting it, with all the branches in between.

> **INFO:** Loren accepts PDF files only. It automatically extracts metadata (title, author, genre, page count, year, publisher, series) from the PDF's internal data and content. If metadata is missing or noisy, it falls back to the filename.

- **➕ Add Single Book**: Tap the + button → "Add a book". Pick one PDF from your device. Loren processes it automatically — extracts text, metadata, and generates a cover image from the first page.
- **📁 Add Folder of Books**: Tap + → "Add a folder". Pick an entire folder of PDFs. Loren asks: Keep as a folder (groups them) or Add individually (flat list). Processes up to 300+ books safely with memory management.

- **✏️ Edit Book**: Long-press a book → Edit. Change title, author, description, genre, tags, and add your own cover emoji.
- **📝 Annotate Text**: Open a book → tap Edit. A rich text editor lets you write and format notes directly on the book's extracted text.
- **🗑 Delete / Trash**: Delete sends a book to the Trash. Trashed books are hidden from recommendations and search but can be restored.
- **⬇️ Download PDF**: Re-download the original PDF file to your device from the book card actions.
- **✓ Mark as Read**: Mark any book as finished. Read status affects Loren's recommendations and shows a green badge on book cards.
- **🤍 Favorite**: Heart icon on any card saves to Favorites. Favorites influence what Loren recommends to you.

### Library Views

- **☰ List View**: Horizontal rows. Compact cover on the left. All action buttons (Open, Download, Notes, Edit, Remove) always visible. Best for managing many books.
- **⬜ Grid View**: Single-column poster cards. Large cover fills the card. Title shown at the bottom. Tap to reveal action overlay. Best for visual browsing.
- **⠿ Shelf View**: Three-column dense grid. Portrait covers like a real bookshelf. Tap for Open + ··· overlay. Best for large libraries.

### Folders

- **Create a folder** — Tap the folder icon in the search bar, or ask Loren "create a folder called TBR". Name it, pick a color.
- **Add books to a folder** — Drag and drop books onto the folder chip, or ask Loren "add Dune to my Fiction folder".
- **Multi-select** — Long-press any book to enter multi-select mode. Select multiple books, then move all to a folder at once.
- **Smart Folder detection** — Tap the ✨ smart folder button. Loren scans your library and suggests groupings based on author, genre, or series.
- **Folder colors** — Each folder has a color that appears as a dot on its chip. Colors are set on creation or can be changed when editing.
- **Folder Import** — Importing a folder of PDFs from your device automatically offers to create a matching Loren folder named after the device folder.

### Duplicate Detection

> **WARNING:** Ask Loren "find duplicates" (or it may surface them automatically). A modal shows groups of books with the same title and author. You can review and remove extras. Loren uses title normalization + Levenshtein distance + page count comparison to avoid false matches (e.g. Volume 1 vs Volume 2 are correctly not flagged).

### Wishlist

> **TIP:** You can add wishlist entries — books you want to read but don't have yet. Wishlist items appear in your library but are always excluded from recommendations, trivia, and search results until you replace them with a real PDF.
